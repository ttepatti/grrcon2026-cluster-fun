# Cluster Fun Parts List

This is a list of the parts I used to put together the Cluster Fun benches for GrrCON 2026. Build one! Hack it! Have fun!

| Part Name | Cost | Link | Info |
| --------- | ---- | ---- | ---- |
| Instrument Cluster | $20-50 | eBay | I picked up various cheap instrument clusters on eBay for the village. Anything from ~2010-2020 will be fun to hack and not overly complex. |
| Laptop Stand | $15 | https://www.microcenter.com/product/706835/laptop-stand-for-desk | The stands used for the clusters were a basic no-frills $15 metal laptop stand from Microcenter. They pivot, they're easy to set up, and they're cheap! |
| Zip Ties | $8 | https://www.amazon.com/Cable-Matters-Assorted-Self-Locking-12-Inch/dp/B00L2LGMO4/ | To attach the clusters to the laptop stands: zip ties |
| CAN Adapter | $19 | https://www.amazon.com/Jhoinrch-Converter-Open-Source-Hardware-Operating/dp/B0CRB8KXWL/ | A cheap CANable USB adapter is perfect for attaching to CAN buses. You might need 2 or more depending on how many buses your cluster has. |
| Jumper Wires | $7 | https://www.amazon.com/Elegoo-EL-CP-004-Multicolored-Breadboard-arduino/dp/B01EV70C78/ | You can use jumper wires to connect to the instrument cluster's pins, that way you don't need a real harness or fancy automotive connector |
| Power Supply | $50 | https://www.amazon.com/Adjustment-Quick-Charge-30V-10A-BLACK/dp/B09BFCF13Y/ | You can use any cheap power supply that will put out 12V at a few amps. This power supply does up to 10 amps, which is more than enough for any instrument cluster. |
