# Introduction to Car Hacking and the CAN Bus

There are TONS of amazing CAN-related resources online – I've included a selection of some of my favorites below.

### Car Hacking Village Recommended Books 

https://www.carhackingvillage.com/books

### The Car Hacker’s Handbook by Craig Smith

This book covers everything from vehicle architectures to CAN bus hacking fundamentals and SO much more! It can be read in PDF form for free online, or can be purchased as a physical volume from No Starch Press.

### CAN Bus Explained – A Simple Intro by CSS Electronics

https://www.csselectronics.com/pages/can-bus-simple-intro-tutorial
https://www.csselectronics.com/pages/can-bus-intros-tutorials

I am a huge fan of all of CSS Electronics’ pages on CAN and automotive networking. There’s a good reason they’re one of the first Google results when you search “introduction to CAN”! Their tutorials are very well laid out, have great diagrams, and are a great intro to the subject.

### CAN DBC File Explained – A Simple Intro by CSS Electronics

https://www.csselectronics.com/pages/can-dbc-file-database-intro

Again, another great tutorial by CSS electronics, this time focusing on the “DBC” database format used by many OEMs and hackers to store information about how to decode proprietary CAN bus messages.

### “awesome-canbus” repository by iDoka on GitHub

https://github.com/iDoka/awesome-canbus

This repo is one of GitHub’s classic “awesome [x]” repos that links to tons of other amazing training, blog posts, books, resources, etc. It covers everything from the basics of CAN to recommended tooling and applications for reverse engineering and analysis.

### "awesome-vehicle-security" by jaredthecoder on GitHub

https://github.com/jaredthecoder/awesome-vehicle-security

Another great "awesome [x]" repo, this time dedicated to general vehicle security topics!

### "awesome-automotive-security" by hexsecs on GitHub

https://github.com/hexsecs/awesome-automotive-security

Another great "awesome [x]" repo, again dedicated to general vehicle security topics.

### SavvyCAN by collin80

https://www.savvycan.com/

SavvyCAN is an amazing GUI-based tool for doing CAN dump logging, analysis, reverse engineering, replay, fuzzing, and much more. In my opinion, it is probably the best free GUI-based tool for performing CAN bus research!

### socketcan & can-utils

https://github.com/linux-can/can-utils

It’s always good to get familiar with the basic Linux CAN utilities. This project includes utilities like “candump”, “cansend”, and other commands.

### gallia

https://github.com/Fraunhofer-AISEC/gallia

UDS-based pentesting tool - "extendable pentesting framework with the focus on the automotive domain"

# Additional Car Hacking Resources & Research

These resources aren't necessarily introductory, but are awesome car hacking resources that I'd recommend checking out or being aware of.

UnlockECU - https://github.com/jglim/UnlockECU

Free, open-source ECU seed-key unlocking tool.

EV-CANlogs - https://github.com/dalathegreat/EV-CANlogs

A collection of CAN logs captured from a wide variety of different electric vehicles.
